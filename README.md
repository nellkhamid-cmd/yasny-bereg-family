# Мини-лендинг «Семейные квартиры» — ЖК «Ясный берег», МЕТА

Свёрстан по ТЗ `../ТЗ мини-лендинг «Семейные квартиры».docx` (версия 1.1 от 09.11.2026). Тексты, цены, платежи и этажи взяты из ТЗ дословно. Ставки ипотеки и телефона застройщика на странице нет.

Сборщики не нужны: откройте `index.html` двойным кликом. Страница проверена в Chrome на ширине 390 и 1440 px.

## Формы и цели Метрики

- **Q1 «Получить каталог»** — 3 шага (квартира → для кого → как покупать) и экран «имя + телефон». Открывается из шапки, экрана 1, карточек, экрана 4 и нижней панели. На экране 4 квиз встроен в страницу.
  - Из карточки квартира уже выбрана, квиз начинается со 2-го шага.
  - Ссылка «Не нашли свою?» открывает 1-й шаг с выбранным «Пока не выбрал(а)».
  - После отправки — экран «Спасибо!» с кнопкой «Открыть каталог (PDF)», PDF открывается в новой вкладке.
- **F1 «Записаться на экскурсию»** — модалка: имя, телефон, когда удобно. После отправки — «Ждём вас!», «Построить маршрут» (Яндекс Карты) и «Посмотреть каталог».
- Общее для обеих форм: маска `+7 (___) ___-__-__`, телефон обязателен. Две галочки, обе по умолчанию не отмечены:
  - «Я согласен с условиями обработки персональных данных и политикой конфиденциальности» — обязательная, без неё заявка не уходит;
  - «Я согласен на получение рекламной и информационной рассылки» — по желанию: согласие на рекламу не может быть условием заявки (38-ФЗ «О рекламе», ст. 18). Уходит в заявку как `ads_consent`.
- Цели вызываются через `goal(name)`: `quiz_start`, `quiz_step_1…3`, `family_catalog`, `catalog_pdf_open`, `family_tour`, `card_2`, `card_45`, `card_319`, `card_250`, `card_754`.
  - Цели карточек срабатывают на любой клик по карточке.
  - Если квиз открыт из карточки, `quiz_step_1` срабатывает сразу: квартира уже выбрана.
- Якоря для быстрых ссылок Директа: `#flats`, `#one-child`, `#two-children` (на мобильном переключают вкладку), `#area`, `#quiz`, `#map`, `#reviews`, `#tour` (сразу открывает F1).
- В квизе на 1-м шаге плитки подписаны «Квартира с 2 спальнями / 3 спальнями» и площадью, без номеров. В CRM номер квартиры по-прежнему уходит в `lot` и `lot_label`.

### Что уходит в заявку — `sendLead(payload)`

```
source_label: "Семейные квартиры"   form: "Q1" | "F1"   form_name
lot: "2" | "45" | "319" | "250" | "754" | "none"   lot_label
family, purchase (ответы квиза)   when (F1)   name   phone: "+7XXXXXXXXXX"
pd_consent: true   ads_consent: true | false (согласие на рассылку)
utm: {utm_source, utm_medium, utm_campaign, utm_content, utm_term, yclid}
page_url, referrer, created_at
```

UTM сохраняются в sessionStorage на время визита. В F1 передаётся квартира, если её уже выбрали в квизе, иначе `none`.

## Что подставить перед запуском

1. **PDF каталога** — положить в `assets/katalog-semeynye-kvartiry.pdf`. Файла пока нет: кнопки «Открыть каталог (PDF)» и «Посмотреть каталог» ведут на этот путь. Без каталога страницу не запускаем — квиз обещает его сразу после заявки. Путь меняется в `CONFIG.CATALOG_PDF` в `app.js`.
2. **Отправка в CRM (Домопланер)** — сейчас `sendLead()` в `app.js` только пишет заявку в консоль. Замените тело функции на запрос к обработчику или к API Домопланера, пример есть в комментарии. Функция должна вернуть Promise: при ошибке пользователь увидит сообщение и сможет отправить ещё раз. В CRM нужна метка «Семейные квартиры» и отметка о встрече.
3. **Яндекс Метрика** — вставить код счётчика в `<head>`, где стоит комментарий, и указать номер в `CONFIG.METRIKA_ID` в `app.js`. Цели с именами выше завести в счётчике как JavaScript-события.
4. **Юрлицо и маркировка в подвале** — строка `Реклама. <юрлицо>, ИНН <…>, erid: <…>` (`#ad-mark`). Нужно уточнить, подходит ли ООО СЗ «Аквастрой» для дома 10 (кв. №754).
5. **Ссылки на документы** — «Политика конфиденциальности», «Согласие на обработку ПДн» (в подвале и в тексте первой галочки), «Согласие на cookie». Для галочки рассылки нужен текст согласия на рекламную рассылку — если юристы дадут отдельный документ, сделать ссылкой и его. Сейчас у них `href="#"` с атрибутом `data-todo`.
6. **utm_campaign** — отдельный для этой страницы, чтобы сравнивать с основным лендингом.
